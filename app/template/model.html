Alur Sistem (Input → Output)

Gambaran perjalanan data dari yang diisi pengguna di website hingga menjadi prediksi.

1. Input User

Form 10 kolom: umur, gender, BMI, durasi tidur, aktivitas, stres, detak jantung, langkah, dan tekanan darah.

2. Preprocessing

→

3. Cari Tetangga

KNN mencari {{ meta.best_params.n_neighbors }} data latih paling mirip, jarak {{ meta.best_params.metric }}.

→

4. Voting

Kelas yang paling banyak di antara tetangga menjadi prediksi, proporsinya menjadi persentase keyakinan.

→

5. Output

Label dan persentase tampil di layar, lalu disimpan ke database untuk halaman Riwayat.

Bagaimana Data Diproses?

  • Input & Validasi: Pengguna mengisi form. Server memeriksa tipe dan batas nilai tiap kolom (Pydantic) sebelum data dipakai.
  • Otomatisasi Pipeline: Data masuk ke file model .joblib yang berisi pipeline utuh. Pengubahan skala dan pengkodean teks dilakukan otomatis di dalamnya, dengan aturan yang sama seperti saat pelatihan.
  • Prediksi: KNN tidak memiliki rumus. Ia membandingkan data pengguna dengan {{ meta.train_rows }} data latih dan mengambil {{ meta.best_params.n_neighbors }} yang paling dekat. Karena berbasis jarak, skala fitur harus seragam.
  • Persentase keyakinan: Dihitung dari proporsi tetangga di tiap kelas.{% if meta.best_params.weights == 'uniform' %} Dengan {{ meta.best_params.n_neighbors }} tetangga yang berbobot sama, nilainya berkelipat 1/{{ meta.best_params.n_neighbors }}, misalnya 6 dari {{ meta.best_params.n_neighbors }} tetangga berarti sekitar {{ "%.1f"|format(600 / meta.best_params.n_neighbors) }}%.{% endif %}
  • Penyimpanan: Hasil dikembalikan ke web dan disimpan ke PostgreSQL agar muncul di halaman Riwayat.
